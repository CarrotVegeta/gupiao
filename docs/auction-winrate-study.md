# 「竞价可买 · 较高概率」封板胜率优化研究

2026-09-18。回答一个问题：竞价页里标成「较高概率」、而且竞价没封板（买得到）的票，
开盘买入后当日收盘涨停的比例只有五成出头，能不能靠**加因子或减因子**提上去。

结论先说：**加特征、减特征都提不动。** 09:25 这个时点的信息已经吃满，封板率天花板约 53%。
真正有效的只有两处：把「昨日换手率」从回归系数改成**筛选门槛**，以及给买入价加**涨幅上限**。
还有唯一一个没被验证过的因子（09:25 竞价量能），需要开始存数据。

复现脚本：

```bash
npx tsx scripts/auction-buyable-lab.ts          # 36 个特征增减变体 + V3 候选
npx tsx scripts/auction-buyable-region.ts       # 结构诊断、阈值扫描、训练区域收窄、两阶段
npx tsx scripts/auction-tier-filters.ts         # 90 个 1~2 元筛选组合
npx tsx scripts/auction-tier-rules-check.ts     # 候选规则的 bootstrap 与留出期复核
```

## 口径

- 样本重建与 `scripts/auction-segmented-model.ts` 完全一致：`limit-up-history.json` + `cache/sina-k-*.txt`，
  用日K的开盘价/昨收重建「竞价是否已封板」，剔除旧生成器污染过的创业/科创/北交 ST。
- **可买** = 09:25 竞价价没有开到涨停价。**胜率** = 当日收盘仍在涨停价。
- 概率全部来自**走前验证**：最初 25 个交易日后每 10 个交易日重拟合，只用预测日之前的样本。
  9,252 条可买样本（140 个交易日），全部样本外。
- 买入价 = 09:25 竞价成交价（= 当日开盘价）。不含手续费与滑点。

## 一、现状：模型没有说谎，53% 就是这个时点的上限

| 指标 | 数值 |
| --- | ---: |
| 可买样本基准封板率 | 14.4% |
| 「较高概率」池（p≥0.40） | **52.7%**（529 条，3.81 只/天） |
| 池内触及涨停（盘中） | 75.8% |
| 池内次日开盘卖出平均收益 | **-0.80%** |
| AUC / Brier | 77.32% / 0.1057 |

阈值往上扫，封板率不再上升：

| 阈值 | 样本 | 封板率 | 触板率 | 次日开盘 | 只/天 |
| --- | ---: | ---: | ---: | ---: | ---: |
| p≥0.30 | 931 | 47.2% | 69.6% | -0.76% | 6.70 |
| p≥0.40 | 529 | 52.7% | 75.8% | -0.80% | 3.81 |
| p≥0.50 | 279 | 55.6% | 76.7% | -0.92% | 2.01 |
| p≥0.60 | 101 | 53.5% | 75.2% | -1.14% | 0.73 |
| p≥0.70 | 28 | 64.3% | 85.7% | +0.24% | 0.20 |

p≥0.40 到 p≥0.65 的封板率全在 52%~56% 之间，**排序在头部已经饱和**。
p≥0.70 那 28 条覆盖 139 天（0.2 只/天），置信区间太宽，不能当规则。

## 二、加因子：36 个变体全在噪声内

对 5 个线上特征做逐一剔除（leave-one-out），再加 26 个单特征、10 个横截面/板块特征、6 组交互，共 36 个变体。
判据是同一个池（p≥0.40）的封板率和整体 AUC。

| 方向 | 结论 |
| --- | --- |
| 竞价涨幅/涨停幅度 | **唯一不可替代**：拿掉 AUC 77.32% → 59.31%，池封板率 52.7% → 31.9% |
| 流通市值对数 | 拿掉 AUC -0.54pp |
| 昨日连板数 | 拿掉 AUC -0.37pp，池封板率反而 +0.3pp |
| 昨日一字板 | 拿掉 AUC **+0.01pp**、Brier -0.0002，池 p≥0.6 封板率 53.5% → 55.7% |
| 昨日换手率（线性项） | 拿掉 AUC **完全不变**（77.323% → 77.323%），等于零贡献 |
| 加：昨日量比、近10日涨停、涨停簇、20日涨幅、距60日高点、昨日振幅、昨日炸板率 | AUC 77.03% ~ 77.69%，池封板率 50.9% ~ 53.2%，无一致改善 |
| 加：市场涨停家数/炸板家数/连板家数、大盘缺口/5日/20日 | 同上，全部落在噪声内 |
| 加：题材强度（同板块昨日涨停家数、板块涨停密度、板块最高板、是否龙头） | 同上；且概念板块互相重叠，`同板块涨停家数` 在池内几乎没有区分度 |
| 加：横截面（当日涨幅分位、连板分位、市值分位、换手相对池中位数） | 同上 |
| 加：非线性与交互（接近涨停、≥7%、低开、竞价×连板、竞价平方、热度×竞价） | 同上 |

另外两条路也试了，同样无效：

- **训练区域收窄**：只用「竞价涨幅≥g」（g=0/2/3/4/5/6%）的样本拟合，把系数集中到真正决策的区域。
  每日前 3 名封板率 53.8% ~ 56.4%，与全样本 55.8% 无实质差别。
- **两阶段排序**：先取基线 p≥0.35 的子样本，再拟一个 8 特征模型重排。前 3 名封板率 56.5% → 55.1%，更差。

> 这与 README 早先的记录一致：09:25 时点的日线衍生特征已经用尽，继续堆只会过拟合。

## 三、减因子：换手率和一字板是死重

由上表，线上 5 个特征里有 2 个可以动：

- **昨日换手率**作为线性项贡献精确为 0。但它在**阈值形式**下有信息（见下节），所以不是删掉，而是改形式。
- **昨日一字板**删掉后 AUC 与 Brier 都略微变好（它想表达的信息已经被竞价涨幅吸收）。

## 四、V3 候选：删死重 + 换手改档位 + 板块密度

按上面的结论组了一版 V3：`竞价涨幅/涨停幅度`、`昨日连板数`、`流通市值对数`、
`昨日换手≥10%（0/1）`、`高换手×竞价强度`、`板块涨停密度`。6 个特征。

| 指标（可买样本） | V2 线上 | V3 |
| --- | ---: | ---: |
| 走前全期 AUC | 77.323% | **77.410%** |
| 走前全期 Brier | 0.1057 | **0.1053** |
| 池封板率（全期） | 52.7% | 53.4% |
| 每日前 3 名封板率（全期） | 55.6% | 56.7% |
| 留出期（最后20日）AUC | 76.201% | **76.887%** |
| 留出期 Brier | 0.1066 | **0.1055** |
| 留出期池封板率 | 47.4% | 48.8% |
| 留出期池次日开盘 | -2.08% | -1.57% |

V3 满足项目原有的验收规则（留出期 Brier 和 AUC 同时改善），但**封板率只从 47.4% 提到 48.8%**。
它是一次正确的清理，不是「胜率太低」的解药。

## 五、真正有效的两处：把因子放对位置

在 529 条「较高概率」池上穷举 90 个 1~2 元筛选组合，再用**按日 bootstrap**（重采样交易日 4000 次）
和 **6 段时间稳定性**复核。只有两条规则活下来：

### 1. 昨日换手≥10% 且 概率≥0.5 —— 唯一提高封板率的规则

| | 保留 | 只/天 | 封板率 | 相对池的提升（95% 区间） | 次日开盘 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 规则 | 67 | 0.60 | **65.7%** | **+13.7pp [+0.8, +26.4]** | +0.46% |
| 池基准 | 529 | 4.72 | 52.7% | — | -0.80% |

- 6 个连续时间段内**全部为正**（+4/+27/+1/+28/+38/+10 个百分点）
- 最后 20 个交易日留出期：规则 55.0%（n=20） vs 池 45.8%（n=83）
- 门槛敏感性：≥8% 时 63.2%（+12.2pp，区间不跨 0）、≥10% 时 65.7%、≥12% 时 61.7%、≥15% 时 59.4%，
  没有单点尖峰，是一段平台

**为什么模型自己学不到**：线上把换手率当线性项送进逻辑回归，标准化后 `权重/标准差 ≈ 0.001`，
再叠 L2 正则，等于被抹平。把同一个变量做成阈值特征加进模型，池封板率只从 55.6% 涨到 56.2%。
**这个因子必须放在筛选项上，不能放在回归系数里。**

### 2. 竞价涨幅≤7% —— 不提高封板率，但提高收益

| | 保留 | 只/天 | 封板率 | 次日开盘 | 收益差（95% 区间） |
| --- | ---: | ---: | ---: | ---: | ---: |
| 池基准 | 529 | 4.72 | 52.7% | -0.80% | — |
| 涨幅≤7% | 213 | 1.90 | 51.2% | **+0.19%** | **+1.69pp [+0.37, +2.91]** |
| 涨幅≤7% 且 概率≥0.5 | 85 | 0.76 | 52.9% | **+0.86%** | **+2.01pp [+0.25, +3.70]** |

6 个时间段里收益差 5 正 1 平（+0.2/+2.0/-0.1/+4.0/+2.3/+0.6），留出期也更好（-0.85% vs -1.95%）。
池内按涨幅拆分看得很清楚：

| 池内分组 | 样本 | 封板率 | 当日收盘卖 | 次日开盘卖 |
| --- | ---: | ---: | ---: | ---: |
| 涨幅 3~5% | 136 | 52.9% | -0.74% | **+0.07%** |
| 涨幅 5~7% | 68 | 48.5% | -1.53% | **+0.17%** |
| 涨幅 7~9% | 179 | 51.4% | -2.24% | -1.49% |
| 涨幅 ≥9% | 137 | 56.9% | -2.66% | -1.44% |

**高开的票封板率最高，但买入价已经把这份确定性付掉了。** 想赚钱要压买入价，不是追封板率。

## 六、唯一还有空间的因子：09:25 竞价量能

上面的搜索覆盖了所有能用日线重建的因子。剩下真正可能有增量的是**竞价量能（竞昨比）**，
线上 `/api/auction` 已经在算 `auctionRatio = 竞价成交额 / 昨日全天成交额`，但**没有历史样本**，
所以一直无法回测（README 也记录了这条限制）。本次尝试补齐历史，三条路都不通：

| 尝试 | 结果 |
| --- | --- |
| 腾讯分笔 `stock.gtimg.cn/data/index.php?appn=detail&action=data&c=sh600519&p=0&d=<日期>` | `d` 参数被忽略，永远返回当日 |
| 腾讯 `action=download&d=<日期>` | 返回「暂无数据」 |
| 网易 `quotes.money.163.com/cjmx/2026/20260909/0600519.xls` | 本机 502（上游不可达） |
| 新浪 `CN_Bill.DetailList?date=` | `Service not found` |

**所以只能从现在开始攒。** 服务端已经按交易日缓存竞价格，顺手把那一天每只候选的
`竞价价 / 竞价成交额 / 竞昨比 / 概率 / 是否封板` 落盘成 JSONL，积累 40~60 个交易日后
就能用同一套走前验证脚本检验竞昨比是否值得进模型。这是唯一还有实质上升空间的方向。

## 七、结论

1. **加因子/减因子都提不动封板率。** 唯一有信息量的是竞价涨幅，而它就是要付的价格；
   36 个模型变体全部落在噪声内。
2. **要减的是两个死重**：昨日换手率的线性项（AUC 贡献 0）和昨日一字板（删掉略好）。
   V3 按这个思路重做后留出期 AUC 76.20%→76.89%、Brier 0.1066→0.1055，但封板率只 +1.4pp。
3. **要加的不是系数，是门槛**：`昨日换手≥10% 且 概率≥0.5` 把封板率从 52.7% 提到 65.7%，
   这是 bootstrap 区间不跨 0、6/6 时间段为正、留出期也成立的唯一一条。
4. **胜率和赚钱是两件事**：`竞价涨幅≤7%` 不提封板率，但把次日开盘收益从 -0.80% 拉到 +0.19%。
5. **不换时点就没有大突破。** 想要更高的胜率，只能引入 09:25 之后的信息（封单量、开板次数、
   竞价量能），而不是继续在日线上找因子。

## 局限

- 留出期只有 20 个交易日；第五节的两条规则是在 529 条上从 90 个组合里选出来的，
  bootstrap 区间已经接近 0，属于**强线索而非定论**，必须用新交易日再确认一次。
- 回测里的昨日换手率由新浪日K成交量 / 流通股本重建，线上取东财涨停池的 `hs` 字段；
  两者口径接近但不完全一致，`10%` 这个门槛在线上需要重新标定。
- 竞价「未封板」不保证能按开盘价成交；收益未扣手续费与滑点。
- 板块归属用的是抓取时点的概念/行业成分快照，不是逐日复原。
- 9 月 18 日的数据未参与拟合或门槛选择。
