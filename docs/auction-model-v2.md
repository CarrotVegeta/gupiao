# 竞价模型 V2：分组校准与条件设置

> **2026-09-18 起线上已停用本模型。** 竞价判定改成
> `src/lib/auction-policy.ts` 里的两条件合格判定（竞价高开 2%~6% 且竞价量比 ≥5%），
> 不再输出封板概率。本文件记录的概率模型与系数保留在 `server/auction/model.ts` /
> `model-parameters.ts` 供离线研究，`scripts/auction-*.ts` 仍在用它做走前验证。
> 停用原因见 [竞价胜率研究](auction-winrate-study.md)：可买样本的封板率天花板约 53%，
> 加/减因子都提不动，而 09:25 竞价量能才是唯一还有空间的方向。

2026-09-18。本次改善的是概率口径和校准，尚未证明可买候选命中率或收益提高。源码修改未自动发布到运行服务。

## 本次改动

1. 已封板和未封板分别拟合逻辑回归，线上根据实际竞价价与涨停价选用模型。
2. 使用竞价涨幅/板块涨停幅度。例如主板高开5%与20%板高开10%均为0.5，避免把绝对高开幅度当成同等强度。
3. 其余特征为昨日连板数（上限5）、昨日一字板、昨日换手率、流通市值对数。特征变换由训练及推断共用。
4. 剔除旧模型中的三个市场特征。旧脚本对 `000001` 使用股票前缀，实际读入平安银行而线上取上证指数；已将历史指数改为 `sh000001`，使用单独缓存。旧市场家数由日K重建，和线上池口径不同，在对齐前不使用。
5. 已封板判定优先采用行情涨停价，否则用昨收和对应涨停幅度计算到分币；取消0.3个百分点的近板近似。价格未知不猜测。
6. 统一分档及缺失门槛；不再将低概率称为“不合格”，不再将未涨停称为“可买”，不再把溢价档位称为收益性价比。

## 默认条件与怎么设置

唯一配置文件：`src/lib/auction-policy.ts`。

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| `qualifiedProbability` | 0.40 | 收盘封板概率≥40%，显示“较高概率” |
| `watchProbability` | 0.30 | 30%≤概率<40%，显示“观察”；低于30%显示“低概率” |
| `maxMissingFeatures` | 1 | 五项有效特征最多缺1项；缺2项及以上暂停概率分档 |

阈值应满足 `0 < watchProbability < qualifiedProbability < 1`。值使用0～1而非整数百分比。
更改配置后需要重新构建并重启实际运行的服务。概率列颜色、筛选名称与服务端分档共用配置。
“竞价未涨停”按钮与概率分档可以组合筛选；这是观察池，不是已验证的自动买入规则。
没有设置高开≥X%、竞昨比≥X%、固定连板数的额外硬条件：现有证据不足，新增阈值需重新按时间验证。

40%阈值在开发期走前验证中确定；不是把旧55%模型直接调低。新版的特征、分组和概率尺度已变化。模型系数在 `server/auction/model-parameters.ts`，不要手工调权重。

## 数据修正

旧生成器把创业板/科创板ST也按5%处理，污染了候选、连板数和标签。新版先按板块确定涨停幅度；训练整组剔除旧数据中542条受污染记录（59只股票，无残留），而不是只改特征后保留错误标签。暂未重建这组历史，因此不宣称对该组校准已验证。
规则核对来源：[深交所风险警示涨跌幅说明](https://www.szse.cn/www/investor/knowledge/stock/deal/t20210127_584469.html)、[上交所科创板说明](https://edu.sse.com.cn/tib/qa/)。

修正数据后按原定模型、40%/30%阈值重跑，未根据重跑结果再次调参。下表为剔除后的最终结果，替代首次未清理数据的统计。旧基线的市场家数仍保留其原有重建口径（含误计的ST），所以这是相对旧口径的比较；新版完全不使用这些家数。

## 验证方法

- 输入：项目已有 `scripts/output/limit-up-history.json`，配套 `scripts/output/cache/sina-k-<symbol>.txt`。
- 使用日K开盘价和昨收重建准确的竞价是否涨停；不能用字段 `oneWord` 代替，因为该字段在旧样本中指昨日一字板。
- 11,596条共同完整样本，日期2026-02-27～09-16。分类训练不再剔除缺少次日收益的最后交易日。
- 2026-08-20之前为开发期，最初25个交易日后每10个交易日重新拟合，只使用预测日前的样本。
- 最后20个交易日（08-20～09-16）为固定留出期。旧/新模型均只用08-20之前数据拟合后评估，留出期内不重训。
- 对比相同未封板样本；同时报告阈值池和每日前三名，避免改变候选数量后只挑好看的比例。
- 最终部署参数在方法锁定、留出检验结束后用全部截至09-16数据重拟合。留出指标来自训练截止08-19的模型，不能把最终参数在这些天的重算结果称为样本外。
- 9月18日不参与拟合或阈值选择。

## 验证结果（没有只报告改善项）

| 未封板组指标 | 旧模型 | V2 |
| --- | ---: | ---: |
| 开发期样本 | 8,043 | 8,043 |
| 开发期Brier | 0.11007 | 0.10558 |
| 开发期AUC | 0.75903 | 0.77537 |
| 留出期样本 | 1,209 | 1,209 |
| 留出平均预测封板率 | 15.88% | 14.76% |
| 留出实际封板率 | 14.56% | 14.56% |
| 留出Brier | 0.10765 | 0.10661 |
| 留出AUC | 0.76000 | 0.76180 |
| 留出每日前三名触板率 | 80.0% | 80.0% |
| 留出每日前三名收盘封板率 | 53.3% | 51.7% |
| 留出每日前三名次日开盘平均收益 | -1.39% | -2.08% |

留出期旧≥55%池39条，封板56.4%、触板87.2%；新≥40%池80条，封板50.0%、触板83.8%。两个池覆盖数量不同，不能声称新阈值提高命中率。新池平均预测52.9%，实际封板50.0%，比旧池预测65.0%、实际56.4%更接近。

已封板组留出样本113条，Brier由0.16416降到0.15854，但AUC由0.67246降到0.62657；该组排序没有改善。完整机器可读结果见 [验证结果](auction-model-v2-validation.json)。

## 仍需验证的地方

- 数据使用抓取时点的名称及流通股数，未逐日复原，存在历史ST状态、股本变化及除权影响；本次未重新构造完整无偏历史行情。
- 没有历史09:25竞价金额、买卖挂单和题材强弱快照，不能可靠检验量能、撤单及板块联动条件。
- 收盘封板与盘中触板仍是两种结果；当前只输出收盘封板概率，触板仅作为验证指标。
- 次日收益未扣手续费及滑点，竞价未涨停不保证能按开盘价成交。新版没有证明正期望买入规则。
- 留出期只有20个交易日且改进幅度小。后续应固定V2参数记录新交易日，再检验分档校准、每日前N名和收益，不能反复用同一留出集调参后继续称其独立验证。
