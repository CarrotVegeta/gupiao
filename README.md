# 股票持仓看板

这是一个用于个人跟踪持仓、分组、成本和实时行情的本地 Web 应用。

它是个人记录工具，不是投资建议。

## 本地运行

先安装依赖：

```bash
npm install
```

启动本地开发环境：

```bash
npm run dev
```

然后打开：

```text
http://localhost:5173
```

## 常用校验命令

```bash
npm run typecheck
npm test
npm run build
```

## 本地烟雾测试

建议按下面流程做一次完整验证：

1. `npm run dev`
2. 打开 `http://localhost:5173`
3. 新增股票 `600519`
4. 输入开仓价 `160`，数量 `100`
5. 确认页面显示服务器返回的行情，或者显示“暂无行情/不可用”的可见状态
6. 刷新页面
7. 确认持仓和备注仍然保留
8. 停止开发进程

## 数据保存

- 持仓、分组和备注都会保存在浏览器的 `localStorage` 中
- 本地存储键名为 `stock-dashboard:v1`
- 清空浏览器站点数据会清除这些记录
- 如果本地数据损坏，应用会自动恢复为默认状态

## 行情说明

- 页面行情由本地服务端接口 `/api/quotes` 提供
- 服务端会再去请求公开行情源，因此查询行情需要网络可用
- 如果公开行情源在非交易时间或服务窗口外不可用，页面可能显示上一轮行情、过期行情或不可用状态

## 备注

- 这是一个个人跟踪工具，不应当被视为投资建议
- 若需要复现问题，请同时记录浏览器缓存、localStorage 状态和网络连通性
